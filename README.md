# Davine Technologies - DevOps Internship

This repository contains my practical work completed during the
DevOps Internship at Davine Technologies.

## Weekly Progress

### Week 01 - Linux Fundamentals, Linux Administration & Networking Basics
Linux fundamentals, users and groups, file permissions,
directory management and networking commands.

### Week 02 - Git, GitHub & DevOps Collaboration
Git installation, Git workflow, branching, merging,
Pull Requests, README and .gitignore.

### Week 03 - Shell Scripting, Automation & Web Servers
Bash scripting, automation, Cron jobs, backups,
log management and Apache web server deployment.

### Week 04 - Docker & Docker Compose
Docker installation, Docker architecture, images and containers, Dockerfile, Docker Hub,volumes,
networks, environment variables, port mapping and multi-container applications using Docker Compose

### Week 05 - Jenkins, CI/CD & GitHub Integration
Jenkins fundamentals, installation and configuration, freestyle jobs,declarative pipelines,Jenkinsfile, 
pipeline stages, GitHub integration,webhooks, build triggers, automation and pipeline troubleshooting.

### Week 06 - Infrastructure as Code & Configuration Management
Infrastructure as Code concepts, Terraform fundamentals, providers, variables, outputs, state, modules, Ansible fundamentals, 
inventory,playbooks, modules and Terraform + Ansible workflow for provisioning and configuration management.
