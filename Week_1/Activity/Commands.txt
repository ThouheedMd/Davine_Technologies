WEEK 1 - LINUX COMMANDS CHEAT SHEET (20 Common Commands)
=========================================================

NAVIGATION & FILES
1.  pwd                         Show current directory
2.  ls -la                      List all files with details
3.  cd /path                    Change directory
4.  mkdir -p dir/sub            Create directories (with parents)
5.  touch file.txt              Create an empty file
6.  cp -r src dest              Copy files or directories
7.  mv old new                  Move or rename
8.  rm -r dir                   Remove files or directories
9.  cat file.txt                Display file contents
10. grep "text" file.txt        Search text inside a file

PERMISSIONS, USERS & GROUPS
11. chmod 770 file              Change permissions
12. chown user:group file       Change owner and group
13. sudo useradd -m user1       Create a user
14. sudo groupadd developers    Create a group
15. sudo usermod -aG developers user1    Add user to group

SYSTEM, PACKAGES & PROCESSES
16. sudo apt update && sudo apt upgrade -y   Update packages
17. sudo apt install -y tree    Install a package
18. ps aux                      List running processes
19. top                         Live process monitor
20. kill <PID>                  Stop a process

NETWORKING
hostname                        Show hostname
hostnamectl                     Show/set hostname and OS info
sudo hostnamectl set-hostname devops-server    Set hostname
ip addr                         Show IP addresses
ifconfig                        Legacy IP info (needs net-tools)
ping -c 4 google.com            Test connectivity
ssh user@host                   Connect to a remote system

ENVIRONMENT VARIABLES
export APP_ENV=dev              Set a variable
echo $APP_ENV                   Print a variable
printenv                        List all variables
echo 'export APP_ENV=dev' >> ~/.bashrc    Make it permanent

ARCHIVING
tar -czvf DevOps.tar.gz DevOps/ Create a compressed archive
tar -xzvf DevOps.tar.gz         Extract an archive
