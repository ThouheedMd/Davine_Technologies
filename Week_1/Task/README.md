# Week 1 Task - Linux & Ubuntu Fundamentals

## Overview

The main task for Week 1 was to get familiar with the Ubuntu Linux environment and practice basic Linux commands and administration tasks.

## Tasks Completed

### 1. Ubuntu Installation

Installed and configured Ubuntu Linux to use as the working environment for the DevOps activities.

### 2. Linux Terminal

Practiced basic commands to understand the Linux system and current user environment:

* `pwd`
* `ls`
* `ls -la`
* `whoami`
* `uname -a`
* `date`

### 3. Users and Groups

Created a `developers` group and two users, `user1` and `user2`. Both users were added to the `developers` group.

### 4. Directory and File Management

Created a DevOps directory structure containing:

```text
DevOps/
├── Projects/
│   └── demo.txt
├── Scripts/
├── Logs/
└── Backup/
```

### 5. File Permissions

Practiced changing and checking Linux file permissions using `chmod` and `ls -l`.

### 6. Basic Networking

Practiced basic networking commands:

* `hostname`
* `hostnamectl`
* `ip addr`
* `ping -c 4 google.com`

## Outcome

By completing these tasks, I became familiar with the Ubuntu terminal and basic Linux administration. I also practiced working with users, groups, files, directories, permissions, and basic network information.
