WEEK 1 - WEEKLY TASK: Linux Fundamentals, Administration & Networking
=====================================================================

1.  Install Ubuntu (VirtualBox / VMware / WSL)
    lsb_release -a

2.  Explore the Linux file system
    ls /        cd /etc        cd /var/log        tree -L 1 /

3.  Create and manage users and groups
    sudo groupadd developers
    sudo useradd -m user1
    sudo passwd user1
    sudo usermod -aG developers user1
    id user1

4.  File and directory management
    mkdir -p practice/docs
    touch practice/docs/file1.txt
    cp practice/docs/file1.txt practice/file2.txt
    mv practice/file2.txt practice/renamed.txt
    rm practice/renamed.txt

5.  File permissions and ownership
    ls -l practice/docs/file1.txt
    chmod 640 practice/docs/file1.txt
    sudo chown user1:developers practice/docs/file1.txt

6.  Install and update packages
    sudo apt update
    sudo apt upgrade -y
    sudo apt install -y tree curl

7.  Monitor running processes
    ps aux
    top
    kill <PID>

8.  Environment variables
    export APP_ENV=development
    echo $APP_ENV
    echo 'export APP_ENV=development' >> ~/.bashrc
    source ~/.bashrc

9.  Networking commands
    hostname
    hostnamectl
    ip addr
    ping -c 4 google.com
    ifconfig

10. SSH connection
    sudo apt install -y openssh-server
    ssh user@<ip-address>

    groups, permissions, package management, environment variables,
    networking, SSH and 20 common commands).
