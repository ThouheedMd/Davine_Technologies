WEEK 2 - WEEKLY TASK: Git, GitHub & DevOps Collaboration
=========================================================

1.  Install Git
    sudo apt install -y git      (Linux)     |     git --version

2.  Configure Git
    git config --global user.name "Your Name"
    git config --global user.email "you@example.com"
    git config --list

3.  Create a GitHub account (github.com/signup)

4.  Create a new GitHub repository (github.com -> New -> DevOps-Week-02)

5.  Clone the repository
    git clone https://github.com/<username>/DevOps-Week-02.git
    cd DevOps-Week-02

6.  Add sample project files and commit
    (index.html, style.css, app.py, config.yaml, deploy.sh)
    git status
    git add .
    git commit -m "Initial commit: add project files"

7.  Push to GitHub
    git push -u origin main

8.  Create a new branch and make changes
    git checkout -b feature-login
    (edit app.py)
    git commit -am "feat: update greeting message"

9.  Merge the branch into main
    git checkout main
    git merge feature-login

10. Create a professional README.md  (see project README.md)

11. Configure a .gitignore file      (see project .gitignore)

12. PDF report
    Prepared as Task/Report.pdf (Git, GitHub, workflow, branching and merge,
    rebase, pull requests, README.md, .gitignore).
