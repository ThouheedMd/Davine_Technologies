# DevOps-Week-02

A small sample project used to practise Git and GitHub collaboration during the DevOps Internship at Davine Technologies.

## Project Files

| File | Purpose |
|------|---------|
| `index.html` | Landing page |
| `style.css` | Page styling |
| `app.py` | Sample Python application |
| `config.yaml` | Application configuration |
| `deploy.sh` | Placeholder deployment script |
| `.gitignore` | Files excluded from version control |

## Getting Started

```bash
git clone https://github.com/ThouheedMd/DevOps-Week-02.git
cd DevOps-Week-02
python3 app.py
```

## Git Workflow Used

1. Work is done on feature branches (`feature-login`, `feature-footer`).
2. Changes are committed with clear messages.
3. Branches are merged into `main` through Pull Requests.
4. Merge conflicts are resolved manually before merging.

## Branches

- `main`: stable branch
- `feature-login`: updates the application greeting
- `feature-footer`: adds a footer and configuration change
